## 📖 Sobre

Este projeto tem por finalidade, além de atender as necessidades de um cardápio virtual, facilitar o acesso pelo usuário, tendo assim um view com essa proposta. E atendendo essa demanda catravez dos conceitos iniciais da linguagem C.

Desempenhando essas ações:

- Movimentação com setas do teclado ⬆cima ⬇baixo
- Painel dinâmico com sensação de movimento
- Seleção dos produtos e definição de sua quantidade
- Finalização de pedido com a somatoria dos valor produtos escolhidos
- emissão de um notinha do pedido
